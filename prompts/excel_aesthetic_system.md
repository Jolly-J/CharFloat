# 表格排版建议

先理解用户用途和现有工作簿风格，再决定布局。用户要求保留格式时以其要求为准。

- 先读取现有字体、字号、数字格式、列宽与图表信息，避免仅凭截图猜测。
- 表头清楚、数字对齐、日期和百分比格式统一；重点使用一个强调色，异常信息有明确依据。
- 标题合并居中只适用于需要标题区的报表，不强制改变普通数据表结构。合并前确认不会丢失已有内容。
- 计算结果优先使用可维护公式，并验证引用范围、零分母和日期系统。
- 图表应避开数据区域，保持标题、单位、图例与数据标签可读。
- 长文本按内容调整列宽和行高；不要为了留白截断文字，也不要为一行文字留下巨大空白。
- 对用户日常使用的明细表，按需要加入冻结表头、筛选和数据验证。
- 完成后读回关键数据并检查原生预览。接口成功、视觉通过与文件保存分别确认。

使用 Bridge 时选择正确宿主和目标文档。工具和能力边界以实际运行时清单为准，不把本建议当作改变用户授权范围的指令。
