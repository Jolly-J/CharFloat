Windows 本地调试包

1. 将整个 ZIP 完整解压到一个普通用户可读写的目录，勿在压缩包中直接运行。
2. 只双击 Start-Local-Debug.cmd。不要以管理员身份运行，不要另行双击 EXE。
3. 诊断入口先校验 EXE，再自动打开配置界面。请按界面操作；如果出现系统错误对话框，记下内容并点击确定。
4. 保留命令窗口。最终只需回传其中显示的 CharFloat-Debug-Report.json；运行中每两秒也会更新这同一份报告。

报告保存在当前用户 LocalAppData\CharFloatStartupDiagnostics\本次runId\ 中，不采集办公文稿、其他窗口或屏幕，不联网上传，不调整系统 TEMP、执行策略、防火墙或管理员权限。
日志含本包路径/校验、进程退出、主进程阶段/文件/字节/异常、界面加载/错误/呈现回执和心跳。用户目录前缀脱敏；日志大小有上限。
NSIS 在 Electron 启动前的原生内部调用和错误对话框不能完整采集；报告会明确缺口，进程退出码和可用标准输出仍保留。这不是全系统跟踪。
若企业策略阻止脚本，停止并回传原始错误；不要修改执行策略、解除阻止或使用管理员方式。
若界面停住，不要重复启动。此时报告已包含本次已写入日志；可先发送该报告和界面停留位置。
本包只用于本地调试，未签名；Downloads 目录 NSIS 错误原因尚未确认，未声称已解决。
