# 2.1.0 构建保护候选验收

范围：仅构建、打包、测试与开发文档；业务源码、加载项源码、skills/prompts 原稿零修改。
不迁移原生模块，不删除 Agent 必需说明，不安装候选包，不重载用户办公宿主。

## 基线

- 固定提交、前序修改清单与摘要：[baseline.json](baseline.json)。
- 本轮之前的工作区修改：[prior.patch](prior.patch)。它包含已有加载项压缩与打包快捷命令，必须保留。
- 142 个工具的完整静态契约：[tools-before.json](tools-before.json)。只保存工具契约，不保存个人路径和实时状态。

## 本轮结果

- 独立生成 `dist/release-app/`；发布白名单排除旧安装器、旧预加载文件、源码、map、备份和开发规范。
- 两个加载项仅在发布副本混淆；WPS 新指纹与运行时上报一致，开发文件未覆盖。
- skills/prompts 全量逐字保留；发布清单中的哈希与原稿一致。
- 打包前阻止过期副本；打包后验证 ASAR + unpacked；最后重新读取 ZIP 并生成 SHA-256 旁置证据。
- 用原 2.1.0 ZIP 负向验证：新门禁明确拒绝旧安装器、旧预加载、缺失保护清单，不会误判旧包通过。
- 第一次从发布副本打包时，门禁实际发现 asarUnpack 未匹配新源路径、CLI 未解包；修正为带 `**/` 的规则后双平台通过。

详细结果与精确 ZIP 哈希：[results.json](results.json)。原始测试输出（个人路径已替换）：[沙箱运行](tests-sandbox.txt)、[网络权限重跑](tests-network-retry.txt)。

## 验证

- 类型检查、导航检查、能力声明检查、diff 空白检查通过。
- Node 回归共 105 项：96 项在沙箱内通过，9 项被本地监听权限阻止；这 9 项在允许本地监听后全部通过。
- 新增保护测试覆盖：WPS RPC 既有行为回归、注册指纹、Office 注册/零值读取/写入/未知方法错误、源码及旧文件泄露与使用说明缺失门禁。
- macOS 候选包实际可执行文件 + unpacked CLI：无 cli-full.cjs，MCP 142 个工具名称、顺序、说明、schema、只读标记与基线一致；能力资源、提示词和工具调用通过。
- MCP 探针资源取自内容哈希已与候选包核对的发布副本，使用临时运行目录和随机端口；未控制真实办公软件。
- Windows 交叉构建、ASAR/unpacked 与最终 ZIP 静态检查通过；没有 Windows 真机执行证据。

## 交付边界

候选包在 `release/2.1.0-protection/{mac,win}/`，原 `release/2.1.0/` 未覆盖。
候选包未签名，未部署；真实 WPS/Excel 加载与业务验收未完成，不能据模拟测试声称正式发布就绪。

PowerShell、必要调用知识及部分压缩 JS 仍可读；本轮未引入原生核心、授权系统或云服务。
保护目的是抬高静态阅读成本与杜绝误带源码，不承诺无法提取、动态分析或原样复制。
