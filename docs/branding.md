# 字浮品牌声明与维护范围

本项目当前品牌正式统一为「字浮」，英文名为 **CharFloat**。npm 包、CLI 和 MCP 服务标识为 `charfloat`，桌面客户端及 WPS / Microsoft Office 加载项显示「字浮 CharFloat」。

当前源码、配置、官网、技能、开发文档和新生成的加载项不得出现旧品牌的完整名称或标识。`npm run check:brand` 对大小写、空格、连字符、下划线、连续拼写和 URL 编码写法进行检查，发现残留即失败。桌面与官网构建前检查源码，构建后分别检查输出；发布副本生成前后同样检查。

`docs/acceptance/` 内的历史验收材料及 `release/` 内既有发布包保留当时名称和原始证据，不代表当前品牌，不改写旧包或历史指纹。依赖、Git 历史、二进制媒体及本地工作区父目录不纳入文本门禁；生成物通过独立检查模式验证。

旧配置和加载项的升级兼容由 [legacy-brand.ts](../src/main/legacy-brand.ts) 集中管理。兼容标识按词组装，只用于识别旧记录，不用于显示或新建 MCP 条目。配置迁移保留不属于本产品的同名条目；旧插件索引会替换成当前名称，新安装不创建旧品牌目录。若旧目录已经存在，则更新其中的加载项资源，保障正在运行的旧缓存入口能够衔接升级。

WPS 的 RPC 方法、服务协议和既有基础目录标识保持兼容；Microsoft Office 加载项的清单 UUID 与握手协议保持不变；同版本清单的菜单、支持链接或品牌变更仍会被状态检测识别并部署。更换桌面应用标识为 `com.antigravity.charfloat` 后，系统可能需要为新包重新授予权限，须与实际宿主验证分开确认。

当前 npm 注册表尚无公开的 `charfloat` 包。官网与 README 使用桌面客户端提供的本机 MCP 配置，开发者从源码构建本地 CLI；发布 npm 包属于另一个明确的发布操作。
