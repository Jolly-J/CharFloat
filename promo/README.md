# 字浮 CharFloat · 宣传片两套环境（拍摄台本）

这里是**两条宣传片所需的全部东西**：两套录制环境、三个成品的施工脚本、分镜剧本、话术卡、救场台词、开拍检查单。

- 片子形态：**两条独立短片**，各 60–90 秒。片 A「无插件」、片 B「有插件」。
- 录制环境：**macOS + WPS**（已验证路径与工具契约）。
- 云端 AI：**预制对话回放**——提前跑好，录屏时只滚动播放，台词 100% 固定。
- 数据：**全部虚构**，由 [make-props.py](assets/make-props.py) 用 CLI 合成，不含任何真实业务数据。

---

## 一、先看这个：四条命令

```bash
# 0) 链路自检：凭据对不对、WPS 连没连上、当前活动工作簿是哪个（只读，不改任何文档）
python3 promo/施工/build.py --probe

# 1) 复原环境（录坏了随时重来，幂等）
python3 promo/assets/make-props.py

# 2) 跑之前先自检参数契约，不连 WPS、不改文件
python3 promo/施工/build.py --all --dry-run

# 3) 录制时逐步施工（--gate = 每步等回车，导演控制节奏）
python3 promo/施工/build.py --group sheet --gate
```

## 三、两条片子讲的是同一件事的两个结局

用的是**同一份文件**：《月度经营.xlsx》。7 月、8 月已经做好，9 月的分项数据在第二个工作表里、合计还没算。

| | 片 A · 无插件 | 片 B · 有插件 |
|---|---|---|
| 文件去哪 | 上传到 AI 服务器 | **不离开你的电脑** |
| 改的是谁 | 云端重新生成一份新文件 | **你眼前打开的那份** |
| 看得到过程吗 | 看不到，只有结果 | **每一步都在屏幕上发生** |
| 你原有的格式 | 每改一次重造一次，填色 / 公式 / 批注 / 冻结会丢 | 只改目标区域，**其余一个不动** |
| 产出 | 一堆版本：v1 / v2 / 最终版 / 真的最终版 | 原文件被就地改好，文件名和路径都没变 |
| 图表 | 一张**图片**，想改数据得重来 | **原生矢量图表**，随时能改 |
| 加密文件 | AI 打不开，整条路断掉 | 根本不用离开本机，加密不影响 |
| 留痕与回滚 | 无 | **每次写入都有 auditId，可回滚** |

## 四、三个作品（片 B 的核心）

> ⚠️ **2026-09-23 更新**：定稿换成了一套真实版式的三个作品（成本测算评审表 / 五年业务规划 / 经营周报），见 [成品基线/说明.md](成品基线/说明.md)。
> 下面这张表描述的仍是**早前的"月度经营"样例故事**，施工步骤需要按新定稿重写——等确认后再动。

一份三季度数据，在你的桌面上同时产出三种交付物：

| 作品 | 成品（已提前定稿） | 施工步骤 | 单看时长 |
|---|---|---|---|
| 作品一 · 表格 | [月度经营分析报表_成品.xlsx](成品基线/月度经营分析报表_成品.xlsx) | `sheet-01` … `sheet-15` | 约 55 秒 |
| 作品二 · PPT | [2026年三季度经营汇报_成品.pptx](成品基线/2026年三季度经营汇报_成品.pptx) | `ppt-01` … `ppt-08` | 约 25 秒 |
| 作品三 · 文档 | [2026年三季度经营分析报告_成品.docx](成品基线/2026年三季度经营分析报告_成品.docx) | `doc-01` … `doc-10` | 约 30 秒 |

三个成品文件是**审样基线**：施工脚本的每一步，都是为了让 WPS 里的文件一步步长成它们的样子。片尾"三个作品并排"的镜头，可以直接用这三个文件摆位。

**代入感是怎么做出来的**：33 步里没有任何一步是"一次性 flash"。每一步只加一列数、加一条公式、上一次色、插一张图、多一页幻灯片、多一个段落——观众能看清文件是在长。

## 六、边界声明（哪些是真的，哪些是摆拍）

写在前面，避免对外吹过头：

1. **真实可跑**：片 B 的全部 33 步都调用本机 WPS 桥的真实工具（工具名与参数已对运行时契约逐项自检通过）。
2. **真实可验证**：加密道具是真加密——macOS `file` 判定 `CDFV2 Encrypted`，openpyxl 直接拒读，口令可解开；见 [03-加密文件/加密校验报告.txt](env-A-无插件/03-加密文件/加密校验报告.txt)。
3. **摆拍道具**：`env-A-无插件/02-AI返回的文件/` 里那 5 个版本，是**预制产物**，用来稳定复现"每改一次重造一份、格式流失"这一拍。若真实 AI 跑出来的文件更能体现，优先换成真实产物。
4. **不承诺的话术**：不要写"支持全部 Office 技能"这类绝对话术——项目有 `npm run check:claims` 强制宣传文案的能力口径与运行时真值一致。台词里凡是出现数量，都必须有对应证据。
5. **未做真机验收的部分**：PPT 与 Word 通道 README 标注为"基础支持"，本套脚本已按真实契约编写，但**首次运行必须在你的机器上实跑一遍再定稿剧本**。
