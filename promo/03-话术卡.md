# 话术卡（可直接复制粘贴）

原则：**每一句提示词后面都缀上收敛约束**。AI 的回答越短，越容易剪，也越不会跑出剧本。

---

## 万能收敛句（每次粘贴后另起一行加上）

```
只回一句话说明你做了什么，不要贴代码，不要复述我的要求。
```

备用收敛句：

| 想达到的效果 | 加这一句 |
|---|---|
| 回答太长 | `用一句不超过 20 个字的话重新说一遍。` |
| 它开始解释原理 | `不要解释过程，直接说结果。` |
| 它开始猜 | `如果做不到，直接说做不到，不要猜。` |
| 它复述了你的要求 | `不要复述我的要求，只说你做了什么。` |
| 它一次做太多 | `这次只做这一件事，其他的等我再说。` |

# 一、片 A 的话术（云端 AI · 预制对话回放）

**重要**：这四轮对话要**提前跑完**并留在浏览器里。录制时只滚动回放，**绝不再提问**。

## 第 1 轮：让云端 AI 做分析报表

粘贴：

```
帮我把这份表做成一份分析报表。9 月的数据在第二个工作表「9 月明细」里，
分项的合计还没算。做完请用不超过 5 句话说明你做了什么。
```

**核对点（录制前逐条确认，缺哪条就追问哪条）**

| # | 必须出现 | 为什么关键 |
|---|---|---|
| 1 | 提到 9 月营收 108 万、成本 80 万 | 证明它真的算进去了 |
| 2 | 提到"生成了一个新文件，请下载" | 这是"文件走了一趟云端" |
| 3 | **提到原文件的格式/批注/公式无法完全保留，或说明它是重新生成的** | **全片最关键的一句**，片 A 的整个论点靠它成立 |

**追问卡（第 3 条不出现时用）**

```
我原来文件里的单元格填色、批注、冻结窗格、命名区域，在你生成的这份里还在吗？
```

```
你是在我原来那份文件上改的，还是重新生成了一份新的？
```

这两问一定能把"我没法在你的原文件上改"这句话逼出来。拿到了就用这句，拿不到就不录这一拍——**不造假**。

## 第 2 轮：制造版本 v2

```
把标题改成「2026 年 7–9 月经营分析（终稿）」。
```

## 第 3 轮：制造版本 v3（布局被重排）

```
把利润率这一行做得显眼一点，放到前面去。
```

## 第 4 轮：加密文件

上传 `2026年度集团经营数据_机密.xlsx`，粘贴：

```
这份文件能打开吗？
```

**期望回答**：打不开 / 需要密码 / 文件已加密。

**追问卡（它含混其词时用）**

```
你确定打不开吗？里面是一个 Excel 表格。
```

```
那我换成加密压缩包呢？
```

再上传 `2026年度集团经营数据_机密.zip`，复现同样的结果。

# 二、片 B 的话术（本机 WPS · 分 5 句说）

**为什么分 5 句**：一口气全说完，AI 会一次调完所有工具，屏幕上就是"唰一下全出来了"，没有代入感。分开说，文件才会**一部分一部分长出来**。

## 第 1 句 · 让它先看

```
看一下我打开的这份月度经营表，9 月的数据在第二个工作表里。
只回一句话说明你做了什么，不要贴代码，不要复述我的要求。
```

对应步骤：`sheet-01` `sheet-02`（**不改任何文件**）

## 第 2 句 · 并数据 + 补公式

```
把 9 月的收入和成本并进分析表，利润和利润率按 7、8 月的口径补上。
只回一句话说明你做了什么，不要贴代码。
```

对应步骤：`sheet-03` `sheet-04` ★ 画面高潮：108 / 80 / 28 / 25.9% 依次出现

**它应该用公式，不是死数字**。如果它手打了数字，加一句：

```
合计要用跨表 SUM 公式，利润和利润率也要用公式，不要写死数字。
```

## 第 3 句 · 上色，并且明确"别动我原来的"

```
营收增长标蓝、成本增长标黄，别动我原来的格式和批注。
只回一句话说明你做了什么。
```

对应步骤：`sheet-05` … `sheet-08`

## 第 4 句 · 加图

```
在表里加一张营收和成本的趋势图。
只回一句话说明你做了什么。
```

对应步骤：`sheet-09` ★ 必须确认是**原生图表**，不是图片。试一下点选图表能不能出现图表框。

## 第 5 句 · 收尾

```
写一句结论放在下面，然后把文件保存了。只回一句话说说你改了哪些单元格。
```

对应步骤：`sheet-10` … `sheet-13`

## 附：三个作品的后两句（PPT 与文档）

```
用刚才这份数据，做一份三季度经营汇报的演示文稿，先做封面。
```

```
再加一页核心指标、一页趋势图表、一页结论。
```

```
再帮我出一份三季度经营分析报告文档，要有标题、正文、三线数据表和行动建议，最后存成 docx。
```

对应步骤：`ppt-01`…`ppt-08`、`doc-01`…`doc-10`

# 三、另一条驱动路径：终端跑施工脚本

如果 AI 客户端现场表现不稳定，切这条：**同一套 33 步，由脚本直接驱动**，屏幕上一样是一点点长出来。

```bash
# 每步等回车，导演控制节奏（录屏推荐）
python3 promo/施工/build.py --group sheet --gate

# 每步自动停 2 秒
python3 promo/施工/build.py --all --pace 2

# 只重录某一步
python3 promo/施工/build.py --only sheet-09 --gate
```

脚本每次执行都会把原始响应留档到 `promo/录制产出/responses/<step-id>.json`，可作为"这确实是真跑出来的"证据。
