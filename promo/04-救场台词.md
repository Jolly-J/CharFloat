# 救场台词与现场故障处理

现场只有三种事故：**AI 不说人话**、**工具失败**、**宿主异常**。下面每一条都给了动作和台词，照着念就行。

---

## 一、AI 台词跑偏

| 症状 | 动作 | 现场台词（直接对 AI 说） |
|---|---|---|
| 回答太长，一屏放不下 | 让它重说 | `用一句不超过 20 个字的话重新说一遍。` |
| 它开始贴代码 / 讲原理 | 打断，重说 | `不要解释过程，直接说结果，不要贴代码。` |
| 它复述了你的要求 | 重说 | `不要复述我的要求，只说你做了什么。` |
| 它自己加了戏（多改了东西） | **先停下**，看审计记录确认改了什么，再决定要不要回滚 | `这次只做这一件事，其他的等我再说。` |
| 它说"我无法查看你的文件" | 先跑 `--doctor` 确认连接，再说 | `再看一次我现在打开的表格。` |
| 它什么都不说，直接调工具 | 不用管，这是好事，剪掉空档即可 | — |

**通用兜底**：任何一次回答不满意，**不要跟它辩论**，直接重录那一步（`--only <step-id>`）。录屏不是考试，重来是最省时间的。

## 二、工具/桥接失败

先跑这两条定位，别猜：

```bash
node dist/bridge/cli.cjs --status
node dist/bridge/cli.cjs --doctor
```

| 现象 | 真实原因（已证实） | 动作 |
|---|---|---|
| `401 凭据不匹配` | 运行目录和当前这份安装不是同一套 | 检查 `WPS_BRIDGE_HOME`；用桌面端重新启动服务 |
| `目标文档未找到` | 会话锁指向的文档已经不在了（宿主重启后锁没失效） | 重新 `sheet-01` 读一次工作区，锁会自动重建并给出提示 |
| 某一步失败后，后续所有步骤连环失败 | 上一步没成功，状态没到位 | 脚本默认会停下（不做自动跳过）。先修那一步，再从头跑该组 |
| 写入报成功但表里没变 | 宿主返回成功不等于已生效 | 脚本已按真实契约读回核对；仍异常时用 `wps_read_range` 手动读一次确认 |
| 图表插了但没有图形 | 宿主存在"插入成功但不建形状"的情况 | 用 `wps_get_charts` 读回确认；确认没有就重录 `sheet-09` |

**重录单步**（不用重头来）：

```bash
python3 promo/施工/build.py --only sheet-09 --gate
```

## 三、WPS 宿主异常（这几条是真机踩过的坑）

### 1. 长会话后新建文档失败 —— 必须重启 WPS

**症状**：`wps_ppt_manage_slides action:'new_presentation'` 或 `wps_create_workbook` 返回空，文档数不变。
**真实原因**：WPS 在高频调用累积之后会进入"拒绝新建文档"的状态，重启 WPS 立刻恢复。
**动作**：**开拍前就重启 WPS**，不要等到现场。已经踩上时：

```bash
# 保存好当前文件，退出 WPS，重新打开演示文件
python3 promo/施工/build.py --group ppt
```

> 这一条已写进 [00-开拍前检查单.md](00-开拍前检查单.md)。它是**不可逆地浪费时间**的那一类故障，必须提前规避。

### 2. 加载项被 WPS 阻断

**症状**：桥接显示未连接，WPS 里看不到加载项。
**动作**：打开桌面端 →「安装 / 修复加载项」→ `node dist/bridge/cli.cjs --repair-addon` → 重启 WPS。

### 3. 某一类组件连不上（表格连上了，Word / PPT 没连上）

**症状**：表格部分正常，一切到 `--group doc` 或 `--group ppt` 就失败。
**真实原因**：加载项是**按组件分别连接**的——实测只开着表格时 `excel.connected = true`、`word.connected = false`。表格连上不代表文字和演示连上。
**动作**：

```bash
# 先在 WPS 里打开或新建一个文字文档 / 演示文稿，再确认
python3 promo/施工/build.py --probe
```

看 `connection.components` 里对应组件是不是 `connected: true`。起来了再跑那一组。

### 4. 操作对象不是你以为的那个文件

**症状**：`build.py --probe` 里活动工作簿是别的表。
**真实原因**：WPS 里还开着别的工作簿。
**动作**：关掉其他工作簿，只留 `月度经营.xlsx`。
**安全性**：施工脚本每一步都显式带 `workbookName`，目标找不到会报错停下，**不会误改别的文件**——但画面会穿帮。

### 5. 绝对不要碰水印参数

`wps_word_page_layout_and_watermark` 的 **`watermarkText` 参数会让 WPS 主进程崩溃**（真机实测 SIGSEGV，可能带走未保存内容）。
**动作**：本套施工脚本**完全没有用它**。任何人临场想"加个水印更正式"，一律拒绝。

### 6. Word 导出 PDF 失败

`doc-10` 是选拍步骤，失败不影响主片。
**动作**：跳过这一步，直接录保存 `.docx` 的镜头（`doc-09`）。

## 四、降级方案（可以剪，但不能骗）

如果某一拍**死活跑不出来**，按这个顺序降级：

1. **换路径**：AI 客户端驱动不出来 → 改用终端施工脚本驱动（同一套 33 步）。
2. **换机器**：这台 WPS 版本有问题 → 换一台按检查单重配。
3. **剪掉这一拍**：宁可少一个卖点，也不要一个假的镜头。
4. **用成品基线文件做静态镜头**：可以用 [成品基线/](成品基线/) 里那三个文件拍"最终成果"的空镜，**但字幕里不能出现"这是它刚刚生成的"**——静态素材只能当结果展示，不能当过程证据。

**唯一红线**：不要把摆拍素材放在"真实运行"的叙事里。片 A 的 `02-AI返回的文件/` 是预制产物（已在 [05-道具清单.md](05-道具清单.md) 标注），片 B 的每一步必须是真跑出来的。

## 五、开拍前一天：全流程预演

```bash
# 1) 复原环境
python3 promo/assets/make-props.py

# 2) 自检参数契约（不连 WPS、不改文件）
python3 promo/施工/build.py --all --dry-run

# 3) 实跑一遍全流程（不录屏，只看能不能跑通）
python3 promo/施工/build.py --all --pace 1 --skip-optional

# 4) 跑完后与成品基线逐项对照
#    WPS 里的表格 vs 成品基线/月度经营分析报表_成品.xlsx
#    WPS 里的演示 vs 成品基线/2026年三季度经营汇报_成品.pptx
#    WPS 里的文档 vs 成品基线/2026年三季度经营分析报告_成品.docx

# 5) 预演把文件改脏了？一条命令复原
python3 promo/assets/make-props.py
```

预演跑通 = 正式录制只剩下"表演"这一件事。预演跑不通 = 现在改，不要到现场改。
