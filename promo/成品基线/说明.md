### 脱敏做了什么

| 层次 | 处理 |
|---|---|
| 客户 / 项目 / 合作方 / 人名 / 地名 | 全部换成虚构名（映射表见下方"工具"一节，**只在你本机，没进仓库**） |
| 金额 / 产能 / 良率 / 五年目标 | 确定性假造：同一数字永远映到同一个假值，前后一致；不同原值不会撞成同一个假值 |
| 百分比 | 原值不超 100 的，假值也不超 100；区间保持升序（不会出现 `105.56%~91.80%`） |
| **公式里的数字常量** | 也换了（`3000/F36` 的 3000 是真实批次量），同时不动单元格引用 |
| 公式缓存值 | **删除**并置 `fullCalcOnLoad` —— 否则真值仍藏在文件里，打开时按假输入重算 |
| PPT 图表数据标签 | 换了（原件里藏着 `3000`、`4500`、`6000~8000`） |
| PPT 内嵌数据源工作簿 | 换了（4 个 `Workbook*.xlsx`） |
| 文档属性 / 批注作者 / 内嵌工作簿作者 | 洗掉（原件里有真实企业邮箱与昵称） |
| PPT 缩略图 | 置空（否则缩略图里还是旧数字） |

### 验证结论（全部通过）

- 结构：工作表/公式/图表/幻灯片/表格数量与原件**逐项一致**
- 专名：原件所有专名在输出里**一个都不剩**
- 数字：关键金额、五年目标、图表标签、公式常量**均已改写**
- 元数据：作者信息、批注作者、内嵌工作簿作者**均已洗掉**

## 工具在哪

脱敏引擎与映射表**故意放在仓库之外**（`/tmp/sanitize/`）——映射表里有你的真实客户名，进开源仓库就等于又泄露一次。

想长期保留，在终端里执行（这两条只是复制你本机的文件，不涉及仓库）：

```bash
cp -r /tmp/sanitize ~/Downloads/道具文档/_sanitize
```

以后原件更新了，重跑：

```bash
python3 ~/Downloads/道具文档/_sanitize/sanitize.py ~/Downloads/道具文档 <输出目录>
python3 ~/Downloads/道具文档/_sanitize/verify-clean.py ~/Downloads/道具文档 <输出目录>
```
