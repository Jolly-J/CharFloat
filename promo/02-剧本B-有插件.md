# 片 B ·《有插件》分镜剧本

**时长** 90 秒 · **形态** 纯录屏 + 字幕 + 配音 · **环境** `promo/env-B-有插件/` · **宿主** macOS + WPS

**一句话**：同一份做了一半的表，AI 走进你正在用的 WPS，当着你的面把活干完——表格、PPT、文档三份交付一起出来，每一步都看得见、都留痕、都能退回去。

**与片 A 的关系**：两条片子用**同一个文件、同一套数字**。片 A 的每一个痛点，片 B 都有一拍正面回应（对照表见文末）。

## 三、出镜提示词与"只说一句"约束

**关键技巧**：每句提示词后面都缀上收敛约束，AI 的回答就会短、稳、好剪。

```
（粘贴提示词后，另起一行加）
只回一句话说明你做了什么，不要贴代码，不要复述我的要求。
```

完整话术见 [03-话术卡.md](03-话术卡.md)。分 5 句说，比一口气全说完**更好剪**，也更像"人和 AI 一起干活"：

1. `看一下我打开的这份月度经营表，9 月数据在第二个工作表里。` → `sheet-01` `sheet-02`
2. `把 9 月的收入和成本并进分析表，利润和利润率按 7/8 月的口径补上。` → `sheet-03` `sheet-04`
3. `营收增长标蓝、成本增长标黄，别动我原来的格式。` → `sheet-05`…`sheet-08`
4. `在表里加一张营收和成本的趋势图。` → `sheet-09`
5. `写一句结论放在下面，然后保存。` → `sheet-10`…`sheet-13`

## 四、拍摄顺序（建议）

1. **先重启 WPS**（原因见 [00-开拍前检查单.md](00-开拍前检查单.md)：长会话后宿主会拒绝新建文档，且这一步不可逆）。
2. 跑 `python3 promo/施工/build.py --all --dry-run` 自检参数。
3. **先录表格**（`--group sheet --gate`）：0:00–0:58 的全部素材。
4. **再录 PPT 与文档**（`--group ppt --gate` / `--group doc --gate`）：蒙太奇素材。
5. **最后录回滚**：表格录完后马上切桌面端，审计记录还是热的，镜头真实。
6. 每段之间不用重开 WPS；重录某一步用 `--only sheet-09` 只重跑那一步。

## 五、现场要点

- **AI 客户端要露工具调用卡片**：选 Cursor 或 VS Code Copilot 这类会把 tool call 显示出来的客户端。终端版（Claude Code）也能显示，但画面信息密度低，适合做补充镜头。
- **窗口布局固定**：WPS 占屏幕左侧 2/3，AI 客户端贴右侧 1/3 竖排。全片不变，观众视线不用重新找。
- **光标要慢**：AI 写完之后，鼠标点单元格、点公式栏、点图表，每个动作停 1 秒再下一个。观众需要时间理解"这是真在动"。
- **WPS 缩放比例 100%**：串流录制下缩放非整数会糊。
- **保存那一步别跳**：`sheet-13` 的保存是全片最扎心的对比点（"还是那个文件"），镜头务必给文件名和路径。
- **回滚那一拍是真操作**：不要摆拍。工具回滚前会比对区域有没有被后续改动，拒绝时也是真实的（说明见 [docs/validation.md](../docs/validation.md)）。
