# 开拍前检查单

按顺序打勾。**第 2 节的"重启 WPS"不是建议，是必须**——原因写在那一节里。

---

## 1. 机器与系统（提前一天）

- [ ] 关闭系统自动更新与重启提醒（系统设置 → 通用 → 软件更新 → 自动更新关掉）
- [ ] 打开「勿扰模式」（否则录制中弹一条微信就废一条）
- [ ] 退出微信 / 钉钉 / 邮件客户端，或至少退出登录
- [ ] 电池接电源，屏幕亮度固定，关闭"自动调节亮度"
- [ ] 桌面清空（只留本次要用的文件夹），隐藏桌面图标
- [ ] 系统时区/时间显示正常（画面里会出现菜单栏时间）

## 2. WPS 状态（**每次开拍前都做**）

- [ ] **完全退出 WPS，再重新打开**
      > 为什么必须：WPS 在高频调用累积之后会进入"拒绝新建文档"的状态（实测 `Add()` 返回空、文档数不变），**重启立刻恢复**。PPT 那一组要新建演示文稿，踩上就是现场卡死。
- [ ] 只打开 `promo/env-B-有插件/月度经营.xlsx`，**其余工作簿全部关闭**（包括正在用的业务表）
      > 实测：脚本用 `workbookName` 锁定目标，找不到就报错停下，**不会误改别的表**；但画面里出现无关文件一样会穿帮。
- [ ] 确认在**第 1 张工作表「月度经营分析」**，光标停在 A1
- [ ] 底部缩放条拖到 **100%**（非整数缩放串流录制会糊）
- [ ] 公式栏显示打开（视图 → 显示公式栏）——片 A、片 B 都要靠它证明"公式 vs 死数字"
- [ ] 关闭 WPS 的登录弹窗、模板推荐、更新提示
- [ ] 确认窗口位置：屏幕左侧约 2/3，全片不移动

## 3. 桥接服务

**一条命令先看链路**（只读诊断工具，不改任何文档）：

```bash
python3 promo/施工/build.py --probe
```

它一次确认三件事：**凭据对不对、WPS 连没连上、当前活动工作簿是哪一个**。

- [ ] 显示「鉴权与连通：通过」
- [ ] `connection.isWpsConnected: true`
- [ ] 活动工作簿是 `月度经营.xlsx`（**不是别的表**）

需要更深诊断时再跑：

```bash
node dist/bridge/cli.cjs --status
node dist/bridge/cli.cjs --doctor
```

- [ ] `--status` 显示服务在跑
- [ ] `--doctor` 里凭据、端口、加载项三项都正常
- [ ] WPS 里能看到加载项（表格上方功能区）
- [ ] 加载项报"被阻断"时：桌面端 →「安装 / 修复加载项」→ 重启 WPS

- [ ] 施工脚本参数自检通过：

```bash
python3 promo/施工/build.py --all --dry-run
```

### Word / PPT 通道要单独确认

加载项是**按组件分别连接**的，表格连上不代表文字和演示也连上。
> 实测（本机 2.1.0）：只开着表格时 `excel.connected = true`、**`word.connected = false`**。

- [ ] 录 `doc` 组之前，先在 WPS 里**打开或新建一个文字文档**，让文字组件连上
- [ ] 录 `ppt` 组之前，同样先在 WPS 里**打开或新建一个演示文稿**
- [ ] 每换一类组件，重跑一次 `build.py --probe` 确认连接状态
- [ ] 若组件的连接状态始终起不来：按 [04-救场台词.md](04-救场台词.md) §三 处理（先重启 WPS，再怀疑代码）

## 4. AI 客户端（片 B 用）

- [ ] 客户端已登录，模型已选好（**全程不换模型**，换模型等于换说话风格）
- [ ] MCP / HTTP 工具接入正常：发一句"看一下我打开的表格"能读到 `月度经营.xlsx`
- [ ] **新开一个干净会话**（历史记录里有旧内容会污染回答）
- [ ] 把窗口贴右侧 1/3 竖排，工具调用卡片能显示出来
- [ ] 提前把 [03-话术卡.md](03-话术卡.md) 的 5 句提示词放在便签/剪贴板，录制时直接粘贴，**不要现场打字**

## 5. 片 A 的云端 AI（预制对话）

- [ ] 四轮对话**已经跑完**并留在浏览器里
- [ ] 第 1 轮回答里**必须有**"原文件格式无法完全保留 / 是重新生成的"这类句子（见 [03-话术卡.md](03-话术卡.md) 的核对表）
- [ ] 下载得到的 5 个文件已经放进 `env-A-无插件/02-AI返回的文件/`
      > 若真实产物体现不出格式流失，可用 `make-props.py` 生成的预制版本——**它们是摆拍道具，已在道具清单标注**
- [ ] 浏览器只留一个标签页，隐藏书签栏（⌘⇧B），地址栏无个人账号信息
- [ ] 滚动位置停在对话开头，录制时只回放、**不再提问**

## 6. 录制软件

- [ ] 录制区域 = 全屏或固定窗口区域，**分辨率固定 1920×1080**
- [ ] 帧率 30 或 60，麦克风已试音
- [ ] 鼠标点击高亮已开（观众要看清点了哪里）
- [ ] 先录 5 秒测试片，回放确认：字清楚、没有糊、没有系统通知
- [ ] 录制快捷键确认（macOS 系统录制是 ⌘⇧5）

## 7. 文件与道具就位

- [ ] Finder 打开 `env-A-无插件/`，列表视图、状态栏打开（⌘/）、显示修改日期
- [ ] `02-AI返回的文件/` 按修改日期排列，滚轮一滑就是"版本堆积"的效果
- [ ] `03-加密文件/` 里两个加密道具在位（见 [05-道具清单.md](05-道具清单.md)）
- [ ] 桌面端「安全时间机器」页面确认能打开、有历史记录（片 B 回滚那一拍要用）
- [ ] 演示口令写在便利贴上贴显示器边（**镜头不要拍到**）

## 8. 开拍前最后 60 秒

- [ ] WPS 已重启 → 演示文件已打开 → 工作表正确 → 缩放 100%
- [ ] `build.py --all --dry-run` 已通过
- [ ] AI 客户端干净会话已就绪，提示词已在剪贴板
- [ ] 勿扰模式已开，录制已开始
- [ ] **深呼吸，鼠标动作放慢一倍**

---

## 开拍中

- 每一步跑完**多停 1 秒**再动鼠标，给后期留剪辑点
- 某一步失败：按 [04-救场台词.md](04-救场台词.md) 处理，**不要现场排查**
- 单步重录：`python3 promo/施工/build.py --only <step-id> --gate`
- 一段录废了不要紧：整段重录前先跑 `python3 promo/assets/make-props.py` 复原文件
