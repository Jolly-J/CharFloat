# IPC 边界

## 文件地图

- [index.ts](index.ts)：window.api 的受控方法与状态订阅。

## 定位与联动

查 index.ts 中暴露方法，再查 [主进程](../main/index.ts) 同名 IPC 和 [调用方](../renderer/App.tsx)。

## 修改边界

仅暴露所需方法，不暴露任意 IPC、Node 或文件系统接口。参数及响应变更同步三端；状态订阅返回解绑函数，组件卸载必须清理。

## 验证

`npm run typecheck`、`npm run build:main`；订阅和交互在 Electron 中验证。

## 避坑

新增 IPC 只改一端 → 运行时方法不存在或参数不一致 → 三端一起核对 → 实际触发并核验结果，构建通过不代表通道可用。

## 同步维护

文件入口、职责、调用关系或验证方式变化时同步更新本页；新增已证实的重复问题时补充原因、处理方式及证据。其余遵循根目录协作规范。
