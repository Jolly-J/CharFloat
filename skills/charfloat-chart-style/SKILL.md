# Excel 范围与对象工作流

本任务尚未建立宿主与目标上下文时，先读 [共享流程](../charfloat/SKILL.md)；已建立则复用，不重复查询连接与工具清单。

## 读取与执行

| 用户目标 | 最小读取 | 执行与核验 |
|---|---|---|
| 修改数据或公式 | 目标范围、必要公式与维度 | 用范围写入，不逐单元格调用；核对关键值和公式 |
| 统一样式 | 目标区域的样式摘要、合并与尺寸 | 相同样式按区域处理；完成区域后预览 |
| 修改已有图表 | 实际名称、源数据、待改属性 | 定位原对象修改，读回相关属性并预览 |
| 绘图或搭建看板 | 锚点区域几何、现有 Shapes 和数据摘要 | 同组形状一次 JS 批次创建；返回名称和边界，整体预览 |

**搭建整页版面（看板 / 信息图 / 封面页）前先读 [画布版面规范](../charfloat/references/canvas-layout.md)**：它给出纵向节奏算法、"视觉中心"对齐规则、宿主不按请求尺寸创建对象时的读回校正做法、层级与遍历陷阱，以及**交付前的自检清单**。跳过它会做出"能看但很业余"的页面。

`excel_get_range_styles` 使用 `mode: "summary"` 和 `include` 选择需要的字段；只有定位差异时才使用 `cells` 和 `maxCells`。数据过大时分块读取所需范围，汇总可在宿主脚本中计算并返回摘要，避免传回整个工作簿。不能因只读取了样本就声称核验了全部数据。

保留已有内容、数据源和样式，不自动套用统一模板。日期数值结合工作簿日期系统判断；百分比轴保留真实量纲，例如 0.72 对应 72%。

## 图表和原生矢量

没有专用更新工具时，用 [原生脚本](../office-agent-bridge/references/native-scripting.md) 修改已有图表，不能直接推断必须删除重建。仅在无法原位完成且用户允许替换时重建，并保留源数据、位置尺寸、系列、图例和轴设置。

矢量绘图操作 Shapes 层，与单元格和统计图表不同。以目标单元格 Left/Top/Width/Height 为锚点，以 pt 计算布局；默认列宽 48pt、行高 16pt（如 `A1:U42` = 1008×672pt），但每批应先读回真实几何再换算，参见 [多元素构图范例](../office-agent-bridge/references/native-scripting.md)。格式与形状的枚举一律传整数，字符串枚举不报错但静默失效，取值见 [枚举速查表](../office-agent-bridge/references/enumeration.md)。同组矩形、文字、连接线在一个批次内处理；返回稳定名称或 ID、实际几何和完成数量。既有对象按精确名称定位，新建对象记录名称，便于失败后继续。不要用 `Range(...).Group()` 分组（实测产出损坏的分组对象）。

修改后只补读工具结果缺失的关键字段；一组对象完成后再截取整体区域。接口执行、视觉验证和保存是不同状态。审计回滚范围遵循共享流程。
