# Office Agent Bridge 演示编辑

PPT 当前是有限支持场景。先调用 bridge_get_capabilities 和实际工具清单，不把 Windows 分支存在等同于 Windows 实机已验证。

操作前读取演示文稿、真实页面尺寸、目标页和形状元数据。16:9 是比例，不代表固定 960×540 或 720×405；坐标必须取自目标文件。

适合基础文本、形状、表格及页面操作。复杂母版、动画、可编辑嵌入图表与一比一复刻需要单独确认；原生脚本接口不能弥补未经验证的宿主 API。

图表返回成功后还需核验形状类型、系列数据和预览。创建失败必须报告失败；文字框、截图不能冒充可编辑原生图表。图表创建后数据配置失败属于部分完成，需要检查已创建对象，不能盲目重试。

既有 macOS 经验提示图表数据编辑窗口可能触发宿主崩溃。不要主动调用 ChartData.ActivateChartDataWindow 或 ChartData.Workbook 来试探；没有当前版本验证依据时，说明限制。用户同意离线生成时可另选专用 PPT 工具，但不要把其产出算作 Bridge 在线能力。

每页编辑后检查预览，确认无遮挡、溢出、母版重复元素。预览失败、保存未执行或结果未验证必须明确报告。PPT 没有统一审计回滚。
