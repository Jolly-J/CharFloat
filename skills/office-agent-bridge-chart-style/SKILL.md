# 表格图表与样式

先读取 `bridge_get_capabilities` 与工具清单。`excel_get_range_styles`、`excel_get_charts` 可以读取样式和图表元数据，统一入口需传 host。WPS 兼容入口为同名 `wps_*` 工具。

修改前读取工作簿、工作表、目标范围和现有图表信息。优先使用实际 `shapeName` 精确定位，避免按近似标题误删。

- 日期序列号必须结合工作簿日期系统确认，不能默认所有文件都是 1900 系统。
- 百分比轴使用真实数值量纲：数据为 0.72 时轴范围可以是 0.7–1，显示格式用 `0%`，不能写成 70–100。
- 图表参数以 schema 为准；颜色可用 `seriesColors` / `seriesSettings`，轴范围用 `yAxis`。
- 当前没有专用统一 update_chart 工具。用户允许替换对象时才能删除重建，并保留数据源、标题、位置尺寸、图例、标签与轴设置；用户要求保留原图时先说明限制。
- 格式、图表没有统一审计回滚。`patch_cells` 才有值和公式快照。
- 审计支持分页、筛选和单条详情，不要一次拉取全部历史。

完成后读回关键配置并检查原生预览，明确区分“设置接口成功”和“视觉验证通过”。Windows 适配未通过实机验收前，不沿用 macOS 的验证结论。
