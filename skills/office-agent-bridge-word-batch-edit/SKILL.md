# Word 结构与批量改稿

复用 [共享流程](../office-agent-bridge/SKILL.md) 的宿主与精确 documentName；上下文已有连接和工具信息时不再初始化。新建和保存可使用 `wps_word_create_document`、`wps_word_save_document`，以当前 schema 为准。

## 定位一次，按结构执行

局部改稿先搜索或读取目标段落、表格及必要邻接内容；全文任务先取得结构，再分段读取，不在每次修改前重读全文。工具若不提供目标范围或摘要参数，可通过 [只读脚本](../office-agent-bridge/references/native-scripting.md) 返回所需结构，不杜撰工具参数。

将修改整理为目标、原内容、预期内容和格式要求。同类格式操作尽量使用现有批量参数；专用工具不足时，以一节或一张表为边界执行 JS。标题、正文和表格分别处理，避免正文继承标题加粗与字号。

插入或删除会使后续段落索引变化。可从后向前处理已定位范围，或每批重定位受影响锚点；写入前核对目标文本。重复文本必须结合章节、段落或表格位置消歧，不能盲目全文替换。

## 查找、表格与核验

- `^p`、`^t` 和单元格多行文本先做不含 replaceText 的查找，核对匹配范围。对未验证的宿主行为用代表性小批次确认，通过后扩展。
- 二维表格数据先校验目标行列和合并结构，不能把丢弃多余列视为成功。
- 每批返回匹配数、修改数、已完成目标及关键内容的实际读回。失败返回当前步骤，先定位已生效部分再继续，不重复整篇改稿。
- 纯内容修改核对目标文本；字号、段落或表格布局变化检查受影响页面预览，不逐段截图。大批统一格式先验证代表区域，完成后覆盖检查受影响页面。

## 本机没有 Word 视觉预览通路

`wps_word_capture_preview` **未注册成对外工具**（调用报"未知工具"），`ExportAsFixedFormat` 在本机也不落盘，所以文字文稿**取不到真实截图或 PDF**。不要反复试探预览调用；改用脚本读回真实属性作为证据：字体/字号/行距/缩进、`Style.NameLocal`、节与 `PageSetup.Orientation`、页眉页脚文本、`ComputeStatistics(2)` 的页数。收尾时如实说明"结构化读回已做、视觉验证未做"。

结构、样式、书签、域、分节与横向页全都要走 [原生脚本](../office-agent-bridge/references/native-scripting.md)（专用工具没有这些能力），枚举取值见 [枚举速查表](../office-agent-bridge/references/enumeration.md)。

整篇排版可能影响封面和表格，仅在用户要求时执行。需要落盘时保存并核对结果；旧 .doc 另存确认实际格式，不能只看扩展名。Word 没有统一快照回滚，不能用表格 auditId 宣称能撤销全文。
