# WPS Word 批量改稿

先查询工具清单和宿主连接。当前已有 `wps_word_create_document`、`wps_word_save_document` 等工具，不能继续声称无法新建或保存。

多文档使用精确 documentName。修改前读取目标段落或表格；将标题与正文分开替换，避免正文继承标题的加粗和字号。

查找中的 `^p`、`^t` 及单元格多行文本在不同版本中需小范围确认。先做不含 replaceText 的查找，核对匹配范围后再修改。二维表格数据必须与目标结构相符，不能把丢弃多余列视为正常结果。

每批修改后读回。需要落盘时执行保存工具并验证返回结果；只有内存写入成功时，不报告“文件已保存”。旧 .doc 格式另存需确认实际格式，不能只根据扩展名判断。

整篇排版会影响已有封面和表格，仅在用户要求时使用。Word 操作没有统一快照回滚，不用普通表格的 auditId 宣称可撤销全文。
