# 从当前文稿学习样式

适用于修改现有演示文稿；以下示例全部为合成内容。遵循用户最新要求，不把示例数值或配色当成模板。

1. 定位精确 presentationName，读取真实 pageWidth/pageHeight（pt）和当前目标页。请勿从截图像素推定坐标。
2. 读用户指定的参考页；没有指定时选同稿适合本任务的代表页。调用 `wps_ppt_get_slide_shapes`，按需开启 `includeStyle:true`，组内内容需要时再开 `recursive:true,maxDepth:3,maxObjects:200`。默认不读全组；文本仍限200字符，`textTruncated:true` 时按目标脚本补读完整原文。检查 `readSummary.issues` 和 `style.unavailable`。样式里的 null 表示未知，宿主混合值（如 -2）不能当作统一样式。
3. 整理下面的约束清单，区分用户硬要求、样本实测和推导建议。可记录同级间距、父子内边距、栏目基线、字体层级、颜色用途、圆角、背景及母版装饰；不能从一张参考页推定全部页面。语义结构和视觉体系一致，不要求所有页布局相同。
4. 写前重读目标的局部内容与对象标识，保留用户实时编辑。`locator.shapeIdPath` 是按组层级的 ID 路径，不是索引；分组/解组后应刷新。它不自动阻止写入，不承诺跨文稿或删除重建后有效。目标、页码或对象变化时停止旧批次并重新定位。原文、表格、图表数据分别列保留清单；用户未授权不得删减文字，移到备注也不等于保留在页面上。
5. 小批次修改，先做代表页。明确图标（识别主题）与图示（解释对象/关系）的用途；是否使用图片生成取决于用户请求及可用工具。透明图片按实际展示尺寸压缩，保留透明通道与版面尺寸。已有组合图片避免 Copy/Paste 路径，使用已验证的本地图片插入方式；失败先读回，不重放整页。
6. 读回真实字体、文本、几何、段落和边界；按本任务的安全区、内边距与对齐要求核验，保留 unknown 项。分别比较正文、单元格及图表系列。再看真实预览的换行、遮挡、留白和母版重复元素。字体/字重还须属性探针，不能仅凭可能替换字体的导出图判断。取得 PNG 不等于看过画面；没有看图不得声称视觉通过。
7. 保存与修改分开报告：内存修改、保存返回、实际文件核验、视觉验收各是什么状态。PPT 无统一审计回滚，风险批次先用用户授权范围内的完整副本备份。

## 最小约束清单（任务记录，非工具参数）

```json
{
  "target": {"presentationName": "示例.pptx", "slideId": 101},
  "reference": [{"slideId": 100, "shapeIdPath": [10, 12], "observed": {"role": "栏目标题", "fontName": "样本字体", "fontSize": 18}}],
  "hardRequirements": ["保留页面正文与两张原生图表", "沿用用户指定参考页的背景"],
  "allowedChanges": ["按内容重分区域", "调整文本框宽高和换行"],
  "preserve": {"textShapeIds": [20, 21], "chartShapeIds": [30, 31]},
  "visualRoles": {"icons": "栏目导航", "diagrams": "解释流程关系"},
  "unknown": ["尚未读到母版字体来源"],
  "verification": {"properties": "pending", "preview": "pending", "save": "pending"}
}
```

样本字号只适用于该参考对象。页面尺寸、安全区、字号、字体和颜色均从当前稿和用户要求确定，不固定使用某种蓝橙配色或边距。

脚本 guard 可比较 `pres.FullName`、`pres.Slides.Item(index).SlideID` 和局部原文，变化即抛错；仅在脚本实际写出这些检查时有效。当前工具没有自动写入前置条件，也不能用形状数相同证明内容未变。母版来源缺失时用只读脚本按宿主能力补读，不能把页面对象的直接字体冒充母版定义。
